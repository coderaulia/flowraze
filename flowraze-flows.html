Request: POST /auth/password-reset/request (always 200 — no enumeration). Confirm: POST /auth/password-reset/confirm with token + new password. Token TTL: 30 min.

Roles & Access
Four roles enforced at route middleware and frontend guard level
Superadmin
Platform-wide admin. Manages all companies, billing, users globally. Route: /admin/*.
Admin
Company admin. Manages team, settings, subscription, automations, users. Sees all company data.
Manager
Can manage campaigns, view team performance. Scoped to company data. Cannot manage billing.
Employee
Sees own leads/deals/activities only. Read access to shared company data. No admin routes.
Frontend Route Guards
SuperadminRoute — /admin/* blocked for all non-superadmin
CompanyMemberRoute — /company/* requires companyId + non-superadmin role
AdminRoute — sub-routes requiring admin role (users, settings, subscription, automations)
FeatureRoute — checks entitlements.feature before rendering (analytics, automation, campaigns, targets, teamPerformance)
